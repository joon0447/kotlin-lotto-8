# 로또

## 구현할 기능 목록
### 1. 값 입력 받기
- [x] 로또 구입 금액 입력 받기
  - [x] 1,000원으로 나누어 떨어지지 않는 경우 예외 처리 하기
  - [x] 입력값이 숫자가 아닐 경우 예외 처리 하기 
- [ ] 당첨 번호 입력 받기
  - [ ] 당첨 번호는 문자열로 받으며 `,` 으로 구분하기
  - [ ] 번호의 개수가 6개가 아니면 예외 처리 하기
  - [ ] 입력 값이 숫자가 아닐 경우 예외 처리 하기
  - [ ] 번호의 범위가 1~45 를 벗어날 경우 예외 처리 하기
- [ ] 보너스 번호 입력 받기
  - [ ] 번호의 개수가 1개가 아닐 경우 예외 처리 하기
  - [ ] 입력 값이 숫자가 아닐 경우 예외 처리 하기
  - [ ] 번호의 범위가 1~45 를 벗어날 경우 예외 처리 하기

### 2. 로또 발급하기
- [x] 구입합 로또들의 1~45 범위의 번호 6개 생성하기

### 3. 로또 출력하기
- [x] 구입 금액에 맞는 로또 수량에 맞게 `n개를 구매했습니다.` 출력하기
- [ ] 각각의 로또의 번호 출력하기
  - [ ] 번호는 `,` 를 기준으로 6개의 번호 출력
  - [ ] 번호는 오름차순으로 출력하기
  - [ ] 번호의 범위가 1~45 를 벗어나지 않도록 하기
  - [ ] 1줄에는 1장의 로또 번호만 출력하기

### 4. 당첨 내역 출력하기
- [ ] 각 로또마다 번호가 몇개 일치하는지 계산하기
- [ ] 번호 일치 개수는 `3개, 4개, 5개, 5개 + 보너스 번호, 6개` 만 출력하기
- [ ] 각 로또의 전체 개수 중 몇개가 일치하는지 출력하기 `예)3개 일치 (5,000원) - 1개`

### 5. 수익률 계산하기
- [ ] 수익률은 `당첨금액 / 구매 금액 * 100` 으로 계산하기
- [ ] 소수점 둘째자리에서 반올림하기
- [ ] 수익률 출력하기
